# Clock
A simple digital clock made using html,css and javascript.Display real-time hours,minutes,and seconds.
Help to understand the functionality of Date() object to fetch the current time,setInterval to update the clock every second.
updating the time by setting values though textContent property,ensuring that only text inside span element changes by demonstrating basic Dom Manipulation.
Each part of the time is wrapped inside a separate <span>,which makes it easy to target and style them individually using css.
